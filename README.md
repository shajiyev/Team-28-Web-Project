# 2xSAD – Team 28 Website

Team project website for **SITE 1101 Principles of Information Systems** at ADA University (2024),
made by **Samira, Sabir, Aziz and Davud**.

## Pages

| Page | File | What's on it |
|---|---|---|
| Home | `index.html` | Welcome screen with the team name and members |
| About Us | `team-members.html` | Each member's photo, short bio and Codecademy profile |
| Hour of Code | `hour-of-code.html` | How we taught coding to 26 school students, with photos |
| Website Project | `web-project.html` | Report on how we planned, built and tested this site |

## Features

- Responsive layout for desktop, tablet and phone (hamburger menu on small screens)
- Sections fade and slide in as you scroll
- Click any photo to view it full screen (arrow keys, swipe or buttons to browse, Esc to close)
- Back-to-top button on long pages
- Keyboard friendly and respects the "reduce motion" system setting

## Run it

Plain HTML, CSS and JavaScript – no build step. Open `index.html` in a browser
(or use VS Code's Live Server).

## Project structure

```
index.html, team-members.html, hour-of-code.html, web-project.html
styles.css   – all styles
scripts.js   – menu, scroll animations, photo viewer, back-to-top
media/       – logos, icons and photos
```
